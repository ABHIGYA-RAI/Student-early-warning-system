The virtual environment is created and activated.
Then, the packages are installed from the file "requirements.txt".
A smoke test is run which runs the predictions, tables, figures and many more files.

Now, the real OULAD's 7 CSV files must be stored in the "config.yaml" file.

Therefore, config.yaml points to the real OULAD and each function extracted from
main.py will run on it.

The real OULAD dataset has been split into training, validation and testing set
for the baseline, temporal transformer and survival-style models.

LR, Cat and XG are all trained on real OULAD.

LR, Cat and XG are now calibrated with two versions each : Isotonic and Platt.

Uncalibrated LR, Cat and XG are always performing worse than calibrated ones.
In calibrated ones too, the Platt calibrated are performing better than the Isotonic calibrated ones.

During smoke testing it has been found that Logistic misses out more dropouts on both gender
and disablility compared to Cat and XG. XG misses out the least on both even though it misses
out more between male vs female rather than disabled vs normal dropouts.

Even in AU-ROC, XG(0.78) >Cat(0.77)>Logistic(0.63).

In calibration, XG does well overall in Isotonic, raw and Platt.
Now, the real OULAD starts: running the non-temporal pipeline.

The content and the students are all the same for all three types of models. It is only
the way the data has been formatted, to fit with the need of the models, that is different.

Cat, XG and Logistic have been trained on real OULAD.

The calibrators learn how to calibrate by learning from the validation set
where it can see both model-predicted and actual probabilities.
Whereas, the testing set will be used after to actually put calibration to use and
give out the calibrated probabilities.

The end-to-end pipeline runs on OULAD for all five models.🎉🎉🎉

Now, the real research and analysis part begins.
A small step: performance_summary.csv to be analyzed in AUC-ROC.
This tells if the temporals beat the non-temporals.


The five test_predictions file turned out to have different students, therefore the non-temporals
and temporals got to work on different students making the evaluation unfair.

So, a single test table is to be formed for fair comparison.
